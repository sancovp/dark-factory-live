# c11_memory_model

CALL NUMBER: `concurrency_synchronization_primitives_and_memor.c11_memory_model`

Standard C11 specification defining memory orderings: memory_order_relaxed, memory_order_consume, memory_order_acquire, memory_order_release, memory_order_acq_rel, memory_order_seq_cst; defines happens-before and synchronizes-with relations.
