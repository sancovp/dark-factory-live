# Second-Order Lens

**Type:** Lens  
**Rarity:** Uncommon

## Description
A reusable analytical lens that reframes solutions by tracing their downstream consequences. First-order thinking solves the problem. Second-order thinking asks: what problem does this solution CREATE?

## When to Use
- After a solution is chosen
- When a fix worked short-term but the problem recurs
- When evaluating a skill's long-term impact on the ecosystem

## How It Works

### Q1: Who Wins?
After this solution succeeds, who benefits? List all stakeholders.

### Q2: Who Loses?
What problems emerge for whom? What new dependencies form?

### Q3: What If It Fails?
If the solution fails, is the failure reversible? Does it create a worse state?

### Q4: Second-Order Problem
Combine Q2 and Q3. The second-order problem is what you actually need to solve.

## Output
```
## Second-Order Analysis
- Winners: [stakeholder list]
- Losers / New Problems: [list]
- Failure Mode: [what breaks if this fails]
- Second-Order Problem: [the actual problem to solve]
```
