# Recipe: Causation-Inversion Pipeline
Type: Recipe
Output Type: Pipeline (Rare)
Yield: 1 composite skill that traces causes then reframes dependencies

## Ingredients
1. Lens: Causation Lens (from crafted/causation_lens.md)
2. Lens: Dependency Inversion Lens (from crafted/dependency_inversion_lens.md)

## Assembly
1. Capture input claim or system under analysis
2. Apply Causation Lens FIRST: identify mechanism vs correlation
3. If verified/assumed cause, apply Dependency Inversion Lens
4. Synthesize: causal chain + inverted option + trade-offs

## Quality Check
- Without Causation Lens, can you identify causal structure? (Must: no)
- Without Dependency Inversion Lens, can you reframe dependencies? (Must: no)
- Both lenses together produce different output than either alone

## Expected Rarity
- Rare + Rare ingredient lenses = Rare output pipeline
