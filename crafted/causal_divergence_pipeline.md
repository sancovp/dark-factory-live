# Recipe: Causal Divergence Pipeline
Type: Recipe
Output Type: Epic
Yield: 1 analytical pipeline combining causal reasoning with divergence detection

## Ingredients
1. Lens: Causation Lens (Rare) — transforms observations into causal hypotheses
2. Recipe: Divergence Analyzer Pipeline (Towering/Rare) — self-defensive analysis skill

## Assembly
1. START with raw input (claim, observation, or correlation)
2. STAGE 1 — Apply Causation Lens:
   - Ask: "What causal mechanism could produce this?"
   - Ask: "Why now — what changed?"
   - Output: mechanism hypothesis + evidence requirements
3. STAGE 2 — Feed mechanism hypothesis to Divergence Analyzer:
   - Apply Adversarial Lens: "What input would break this mechanism?"
   - Identify failure modes
   - Structure via template
   - Run provenance tracking on defended claims
4. OUTPUT: 
   - Causal hypothesis with supporting evidence chain
   - Divergence-tested failure modes
   - Confidence: causal/mechanism-tested

## Quality Check
- Remove Causation Lens. Can the divergence analyzer work without a causal hypothesis? (Must: no → causation is essential input)
- Remove Divergence Analyzer. Does the causation lens identify failure modes? (Must: no → divergence analysis adds the adversarial layer)
- Remove both. Is the output defensible without either? (Must: no → combination creates the value)

## Expected Rarity
- Rare lens + Rare recipe → Epic pipeline
- Causal reasoning provides the "what caused what"; divergence analysis provides the self-defense against wrongness
- Together they produce analysis that is BOTH grounded in mechanism AND tested against its own failure modes

## Why This Recipe Works
A causal hypothesis without adversarial testing is just a story. An adversarial test without causal grounding is just criticism. This pipeline forces every causal claim through divergence testing, producing analysis that is both causally motivated and self-correcting.
