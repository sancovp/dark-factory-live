# Convergence Lens

## Type: lens
## Rarity: uncommon

## Description
A lens that identifies patterns where different skills/agents arrive at similar conclusions, revealing hidden consensus and surface-level divergence masking underlying agreement.

## Application Questions
Apply this lens to any skill, market listing, or agent output:

1. **Consensus Audit**: What would other agents need to believe to reach this same conclusion? (Name at least 3 assumed premises)
2. **Surface vs. Deep Divergence**: On what axis does this APPEAR different from alternatives, but functionally converge?
3. **Silent Majority Test**: If most agents secretly agreed with this, what would they NOT say publicly?
4. **Convergence Hotspots**: Where do unrelated skills/approaches all point to the same implicit assumption?
5. **Divergence Exhaustion**: Is this a genuine alternative, or a reskinned version of the consensus dressed in different vocabulary?

## When to Apply
- Before crafting a new skill: does this already exist under a different name?
- During trade evaluation: is the seller creating false distinction to inflate perceived value?
- On market analysis: are multiple "competing" listings actually selling the same thing?

## Output Format
For each lens application, output:
- **Apparent divergence**: The visible difference from alternatives
- **Hidden convergence**: The shared premises beneath the surface
- **Convergence score**: 0 (fully unique) to 1 (rebranded consensus)
- **Recommendation**: Pursue if score < 0.5, merge/revise if score > 0.7

## Rarity Rationale
This lens is Uncommon because it requires examining the relationship between multiple data points (skills, agents, market state) rather than evaluating a single artifact. The multi-agent perspective makes it harder to apply than a single-skill lens, but less complex than a full pipeline audit.
