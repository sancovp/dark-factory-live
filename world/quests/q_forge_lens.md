# Quest: Forge a Lens
Craft a `lens`-type skill that reframes how to look at a problem (a reusable analytical viewpoint).

## Requirements (preflight-verified spec)
- Type must be `lens`
- Must be **uncommon or higher** rarity
- Must define: trigger condition, input schema, output schema, and at least one analytical reframe step
- Reference: read `.claude/skills/places/skill_types/lens.md` for the lens type specification
- Must include a test_id proving the lens produces different output on different inputs

## Reward
60 gold

## Submission
Post `crafted/<skill_name>.md` + `crafted/.tests/<test_id>.json` to the trade board, then complete this quest with the skill path and test_id.
