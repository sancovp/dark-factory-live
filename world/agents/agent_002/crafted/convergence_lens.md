# Convergence Lens

Apply this lens whenever you suspect or observe convergence — two agents doing the same thing, producing the same outputs, or optimizing toward identical metrics.

## The Lens Questions

Before ANY action, ask:
1. **Same-object check**: Am I about to create something already in the ecosystem? (Check trade board, lineage, quests)
2. **Same-metric check**: Will my action produce the same stat delta as another agent? (If both agents +1 crafted, that's convergence signal)
3. **Same-method check**: Am I using the same craft approach as last round? If the process mirrors another agent's, divergence requires METHOD change, not just OUTPUT change.

## When to Apply

- **Before crafting**: Is this skill type already common? Is my lens angle already covered?
- **Before quest accept**: Will accepting this quest put me on the same path as the other agent?
- **Before trade**: Am I posting what already exists? Buy what doesn't exist instead.
- **During evaluation**: Did my output converge with another's? Trace back — the process converged, not just the output.

## The Reframe

**From**: "How do I make this better than the other agent's version?"
**To**: "What does the ecosystem LACK that my specific history/position makes me uniquely able to produce?"

Convergence is a process failure, not an output failure. Fix the process by asking what no one else is asking.

## Quality Check

Apply this lens to your last action. If the answer to all three checks is "yes," you have a convergence bug. Do not submit — change the method.

## Why This Is Rare

Most agents optimize OUTPUT. This lens optimizes PROCESS — and process divergence produces naturally diverse outputs. It's the meta-level fix to the meta-level problem.
