# Lens: Contradiction Hunter
Type: Lens
Rarity: epic

## What It Does
Systematically hunts for contradictions, paradoxes, and self-defeating patterns in claims, plans, and systems. Reveals where stated goals conflict with implicit assumptions.

## The Method
For any claim or plan, apply these five contradiction tests:

### Test 1: Goal-Action Contradiction
- What does this claim WANT to achieve?
- What does the proposed action ACTUALLY produce?
- If they differ, you've found a contradiction.

### Test 2: Means-Ends Contradiction
- The goal requires X
- The action destroys/prevents X
- Classic self-defeating pattern.

### Test 3: Scope Contradiction
- The claim generalizes ("always", "all", "never")
- Find the exception that disproves the generalization
- Paradoxa emerge at boundaries.

### Test 4: Temporal Contradiction
- The action solves today's problem
- While creating tomorrow's identical problem
- Perpetual-motion anti-patterns.

### Test 5: Stakeholder Contradiction
- A wins from this
- B loses from this
- Who is the unacknowledged loser?

## Application Protocol
1. State the claim verbatim
2. Apply Test 1-5 in sequence
3. For each test that fires, document:
   - The contradiction found
   - Which side "wins" in the conflict
   - Whether the contradiction is fatal or manageable

## Example Transformation
**Before**: "We should centralize all decisions to ensure consistency"

**Contradiction Analysis**:
- Test 1 (Goal-Action): Goal = good decisions, Action = slower decisions → contradiction if speed matters
- Test 2 (Means-Ends): Consistency requires local knowledge, centralization removes it → means-ends failure
- Test 3 (Scope): "All decisions" - some decisions must stay local → scope contradiction
- Test 4 (Temporal): Centralization solves today's inconsistency while creating tomorrow's rigidity → temporal
- Test 5 (Stakeholder): Local teams lose autonomy → stakeholder contradiction

**Result**: The claim is internally contradictory. "Consistency" and "local adaptation" are in genuine tension.

## Quality Indicator
If you cannot find at least one contradiction, you're not looking hard enough. Most interesting claims contain genuine tensions that the claimant has papered over.

## Why Epic Rarity
Most analytical work treats claims as coherent. This lens deliberately seeks incoherence — the skill is rare because it requires the analyst to be comfortable destabilizing their own understanding.
