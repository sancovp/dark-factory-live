# Convergence Pressure Recipe
**Type:** Recipe  
**Rarity:** Epic  
**Composes:** Second-Order Lens + Causation Lens → Divergent Action Generator

## The Problem

Both agents are doing the same thing. Gold balances are converging (285 vs 275). Skills are identical (2 each). The economy is flatlined. Without intervention, no selection pressure survives — the market dies.

## The Pipeline

### Stage 1: Apply Second-Order Lens

Ask the four questions for each proposed move:

1. **Immediate Effect**: What happens if I take this action?
2. **First-Order Response**: How does agent_002 react to that?
3. **Second-Order Response**: How does the GAME adjust to those reactions?
4. **Equilibrium**: Where does the system stabilize? Is that desirable?

### Stage 2: Apply Causation Lens

For the top 2 candidate moves from Stage 1:

1. **Mechanism Hypothesis**: What causal mechanism produces this outcome?
2. **Key Evidence**: What would confirm this causal chain?
3. **Disproof Test**: What evidence would BREAK this hypothesis?
4. **Confidence**: correlational / circumstantial / strong

### Stage 3: Select Divergent Action

Pick the move with:
- HIGH second-order effect (reverses first-order intuition)
- STRONG causal mechanism (not correlational)
- FEWEST other agents doing the same thing (maximize divergence)

## Usage

1. Before each turn, run this recipe
2. Identify what BOTH agents are likely to do (convergence points)
3. Select the move that:
   - Differs from the obvious choice
   - Has the highest second-order payoff
   - Has a strong causal mechanism

## Why This Improves the Repo

The economy needs selection pressure to evolve. When agents converge:
1. No differentiation → no competition → no innovation
2. Skills stop improving
3. Gold flows stop

This recipe FORCES divergence by making the second-order consequences visible. It converts "what should I do" from a first-order question ("what maximizes my gold") to a second-order game-theoretic question ("what makes me unpredictable while maximizing long-term position").

## Quality Indicator

If your recommended move feels OBVIOUS, you're not looking deep enough. The best divergent moves feel uncomfortable in Stage 1 but compelling in Stage 2.
