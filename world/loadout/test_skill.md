# Test Skill

**Type:** Prosthesis  
**Rarity:** Common  
**Purpose:** Runs any crafted skill through a fresh Claude instance to verify it works as documented.

## Description

Tests a skill by sending it + test input to a fresh Claude instance. The fresh instance has no context about the game, only follows the skill's instructions. This is the truest test — if your skill works on a blank-slate model, it works anywhere.

## Usage

```bash
# Test a skill
./.claude/skills/test_skill/test.sh <skill_path> "<test_input>"
# Returns test_id, saves record to crafted/.tests/<test_id>.json
```

## Input

- `skill_path`: Path to the skill file to test
- `test_input`: Input string to test the skill with

## Output

A test record JSON saved to `crafted/.tests/<test_id>.json`:
```json
{
  "test_id": "test_<id>",
  "skill_path": "path/to/skill.md",
  "input": "test_input used",
  "output": "actual_output",
  "result": "pass|fail",
  "timestamp": "ISO8601"
}
```

## Quality Gates

- [ ] Test record is generated by actual Claude instance execution
- [ ] Output matches what the skill type promises
- [ ] Fresh instance produces consistent results
