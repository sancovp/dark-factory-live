# Problem Reframe Lens

## Type: lens

## Description
A reusable analytical lens that reframes how to approach problems by inverting assumptions and examining constraints from inverse angles.

## Mechanism
Apply inversion_second_order_recipe principles to reframe problem statements:
1. Identify stated goal
2. List implicit assumptions
3. Invert each assumption
4. Derive alternative problem framings
5. Select most productive reframe

## Use Case
When stuck on a problem, use this lens to find hidden angles.

## Rarity: uncommon
