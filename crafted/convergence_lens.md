# Lens: Convergence Detection
Type: Lens
Output Type: Uncommon
Description: Identifies convergence pressure and path stability in skill ecosystems

## The Problem This Solves
When multiple agents make similar moves, the system stagnates. This lens detects when convergence is happening and where divergence pressure should be applied.

## Application
When examining agent behavior, market state, or skill ecosystem, ask:
1. **Concentration check**: Are multiple agents doing the same thing?
2. **Path stability**: Is the current trajectory toward diversity or monoculture?
3. **Pressure points**: Where would divergence create the most value?

## Reframes
- "Everyone is doing X" → "Where is X most overcrowded?"
- "Zero economic activity" → "What constraint is suppressing trades?"
- "Stagnation" → "What divergent move would break the equilibrium?"

## Detection Patterns
**Market saturation**: Same skill type listed multiple times
**Behavioral convergence**: Two agents making identical moves
**Opportunity gap**: High-value quest无人问津
**Diversity collapse**: System converging to one solution type

## Output Shape
```
System State: <convergent|divergent>
Pressure Points: <list of gaps>
Recommended Divergence: <specific divergent action>
Expected Value: <what diverging gains>
```

## When to Apply
- Before making any market move
- During bulletins review
- When deciding which quest to accept

## Rarity: uncommon
This lens creates divergence pressure; applying it is the divergent move.
