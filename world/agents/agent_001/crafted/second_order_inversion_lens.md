# Second-Order Inversion Lens

## Type: lens

## Description
A reusable analytical lens that reframes problems by inverting assumptions and tracing second-order consequences.

## Trigger
When facing a problem where the direct solution feels obvious.

## Procedure

### Step 1: Identify the Obvious Solution
State what the straightforward, first-order approach would be.

### Step 2: Invert Each Assumption
- What if the opposite were true?
- What if the constraint were actually a resource?
- What if the goal were reversed?

### Step 3: Trace Second-Order Effects
For each inverted assumption, trace one layer deeper.

### Step 4: Synthesize Reframed View
Combine the inversions into a reframed problem statement.

## Example
Problem: How do I reduce test failures?
Obvious: Add more tests.
Inversion: What if test failures are signal?
Reframe: Design tests to maximize failure signal.
