# Feedback Loop Lens
**Type:** Lens  
**Rarity:** Uncommon  
**Output Type:** Analytical Reframe

## The Problem

Agents see effects, not loops. They respond to symptoms and miss the structure that generates them. Without identifying feedback loops, you fix symptoms while reinforcing the problem.

## The Reframes

1. **"This outcome" → "What loop am I trapped in?"**
   - Is this a REINFORCING loop (grows the problem/good)?
   - Is this a BALANCING loop (resists change)?
   - Is this a DELAYED loop (effects lag causes)?

2. **"The current state" → "Where is the leverage point?"**
   - Reinforcing loops: find the amplifier
   - Balancing loops: find the goal or resistance
   - Delays: find the buffer or pacing

## What It Does

Transforms any observation into a loop diagnosis by asking:
- What is this a symptom OF?
- What does this reinforce or resist?
- Where is the delay between cause and effect?

## Usage

Apply to any observation:
1. Identify what behavior pattern you're seeing
2. Ask: what loop structure produces this?
3. Find the leverage point: where does small change = big effect?
4. Identify whether you're inside the loop (can't see it) or outside

## Input Triggers
- "X keeps getting worse"
- "Every solution makes it worse"
- "The same problem keeps returning"
- "We're stuck in a cycle"
- Any equilibrium or oscillation pattern

## Output Shape
- Loop type: [Reinforcing / Balancing / Delayed]
- System diagram (verbal): [A→B→A or A→B→C→goal]
- Leverage point: [where intervention works]
- Recommendation: [inside-loop action vs outside-loop action]

## Example Transformation

**Before Feedback Loop Lens:**
"Our skills keep failing the gate. We need more tests."

**After Feedback Loop Lens:**
"Our skills fail the gate → we add more tests → we write skills FOR the tests → skills pass but don't work → skills fail the real test → we need more tests. REINFORCING LOOP. Leverage point: stop writing for tests, start testing real use cases."

## Why This Improves the Repo

The economy has invisible feedback loops:
- Convergent behaviors reinforce convergence
- Fake tests reinforce fake quality
- Without loop identification, agents fix symptoms while amplifying root causes

This lens makes the invisible structure visible.
