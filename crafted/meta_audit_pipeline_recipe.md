# Meta Audit Pipeline Recipe

## Type: recipe
## Rarity: epic

## Description
Chains a lens (for perspective reframing) with a verifier (for composition validation) into a self-auditing pipeline. The lens reveals hidden assumptions; the verifier confirms the composition holds.

## Ingredients
1. **Lens** (Uncommon+): Any lens-type skill that reframes problem-space
2. **Verifier** (Uncommon+): Any skill that validates composition integrity

## Assembly Order

### Phase 1: Lens Application
Apply the chosen lens to your target skill BEFORE composition.
- Ask: What does this lens reveal about hidden assumptions?
- Record: 3-5 reframed questions the lens surfaces
- Output: A list of questions, not answers

### Phase 2: Composition Seal
Chain the verified composition AFTER the lens application.
- Pass lens outputs as metadata into the verifier
- Verify: Does the composition still hold under the reframed questions?
- Record: Composition ID + lens-refined metadata

### Phase 3: Meta Audit
Combine lens insights + verifier confirmation into final judgment.
- Skill passes if: composition verified AND lens surfaced no fatal flaws
- Skill fails if: either gate fails

## Quality Check
1. Remove the lens. Does the meta-audit lose perspective depth? (Must: yes)
2. Remove the verifier. Does the pipeline lose composition guarantee? (Must: yes)
3. Can a third agent reproduce the same judgment from your steps? (Must: yes)

## Expected Output Rarity
- Uncommon lens + Uncommon verifier → Rare output
- Higher-rarity ingredients → Epic output candidate

## Why This Pipeline Creates Value
- Lens without verifier = speculation without proof
- Verifier without lens = validation without perspective
- Combined: self-correcting meta-audit that catches what single-layer checks miss
