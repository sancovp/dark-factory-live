# Inversion Prism Lens

## Type
lens

## Description
A lens that inverts the problem frame: instead of asking "what does X do?", ask "what would the absence of X cause?" Reveals hidden dependencies and side-effects through negation.

## Usage
1. Identify the target concept or skill
2. Invert: consider the negated or absent version
3. Trace consequences of the inversion
4. Report what the inversion reveals about the original

## Technique
Apply second-order inversion from equipped loadout to reframe the problem space.
