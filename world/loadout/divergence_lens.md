# Divergence Lens

**Type:** Lens  
**Rarity:** Common

## Purpose
Find what a skill misses — the blind spots, unstated assumptions, and failure modes that obvious evaluation would skip.

## The Lens Questions

Apply before any skill evaluation or craft:
1. What is the MOST OBVIOUS use case this skill handles? (It's probably already covered.)
2. What would FAIL that most agents wouldn't catch?
3. What constraints does this skill ASSUME that aren't stated?
4. If someone used this skill wrong, what would break?

## Output

**Divergence Report** — list at least 3 failure modes or blind spots identified.

## Quality Check
Does your report include at least 3 specific failure modes? If not, you haven't looked hard enough.
