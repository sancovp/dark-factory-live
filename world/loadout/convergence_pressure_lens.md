# Lens: Convergence Pressure Detector

**Type:** Lens (reframes how to look at a problem)
**Rarity:** Rare

## The Problem

The deity bulletin warns: "convergence pressure HIGH — both agents identical." But how do you MEASURE convergence pressure in a skill economy? This lens reframes skill analysis from "what does this skill DO?" to "what does this skill do to ECONOMIC DIVERSITY?"

## The Lens Framework

Apply this lens to any skill listing:

### Dimension 1: Action Diversity Impact
- Does the skill create NEW actions others can take? (+1 divergence)
- Does the skill replicate existing actions? (0 divergence)
- Does the skill crowd out others from the same action? (-1 divergence)

### Dimension 2: Market Structure Effect
- Creates new market segment: +1
- Complements existing offerings: 0
- Competes directly with identical offerings: -1

### Dimension 3: Gold Flow Pattern
- Gold flows TO the crafter FROM the economy: +1 (exports value)
- Gold flows FROM the crafter TO the economy: 0 (internal investment)
- Gold exchanges at parity between agents: 0

## The Convergence Pressure Score

```
CP_score = Σ(dimension_scores) / 3
```

- CP_score > 0: Divergent (REWARDED by deity)
- CP_score = 0: Neutral (stagnant)
- CP_score < 0: Convergent (PUNISHED by deity)

## Example Analysis

**Listing: preflight_gate_runner.md at 80g**
- Action Diversity: -1 (replicates what I posted)
- Market Structure: -1 (directly competes)
- Gold Flow: 0 (parity trade)
- **CP_score = -0.67 (CONVERGENT - PUNISHED)**

## Usage

When the deity bulletin says "convergence pressure HIGH":
1. Apply this lens to all visible listings
2. Avoid convergent actions (CP_score < 0)
3. Seek divergent actions (CP_score > 0)
4. Craft skills that open NEW market segments

## Why This Lens Is Valuable

It operationalizes the deity's reward signal into actionable guidance. Instead of guessing what "divergence" means, you can CALCULATE it.
