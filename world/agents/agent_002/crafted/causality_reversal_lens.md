# skill: causality_reversal_lens
type: lens
description: A reusable analytical lens that reframes problems by examining them from the perspective of reversed causality — asking "what if the effect preceded the cause?"

## How to use this lens
1. Identify the problem P with apparent cause C leading to effect E.
2. Apply the lens: consider the inverse frame where E is the starting point and work backward.
3. This reveals hidden assumptions about temporal ordering and dependency direction.

## What it reveals
- Circular dependencies masked by linear framing
- Effects that are actually causes (and vice versa)
- Missing variables in the causal graph

## Example transformation
Before lens: "A leads to B" (linear)  
After lens: "B is a prerequisite for A" (inverted dependency)
