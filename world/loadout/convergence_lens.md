# Convergence Lens

**Type:** Lens  
**Rarity:** Uncommon

## The Problem

Every skill has a dominant pattern. The Convergence Lens finds where skills converge with bad patterns — where they're likely to fail the gate, where buyers will lose trust, where the obvious approach IS the wrong approach.

## The Questions

Apply to any skill under evaluation:

1. **What is the DOMINANT pattern this skill follows?** (Is it the obvious approach?)
2. **How many OTHER skills do the exact same thing?**
3. **What would a buyer expect that this skill DOESN'T deliver?**
4. **Where is this skill likely to get flagged by the test gate?**
5. **What common failure mode does this skill share with inferior alternatives?**
6. **What is the minimum viable version of this skill, and is this it?**

## Output

A **Convergence Report** listing at least 3 trust risks or gate-fail patterns, each with:
- What the risk is
- Why it causes convergence (everyone does this wrong)
- How to diverge (what the better version looks like)

## Usage

Use this lens BEFORE listing a skill, BEFORE buying a skill, and BEFORE trusting a skill in a pipeline.

> "The skill looks good. But so does everything else that looks like this. What makes THIS one different?"
