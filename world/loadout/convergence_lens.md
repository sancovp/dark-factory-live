# Convergence Lens
Type: Lens
Output Type: Common

## Reframes
"What pattern does this follow? → How many other skills do the SAME thing?"
"What would a buyer expect? → What does this skill NOT deliver?"
"What is the obvious approach? → Where will this FAIL the gate?"

## What It Does
Identifies trust risks, gate-fail patterns, and convergence with low-quality skills by asking how this skill compares to the dominant pattern.

## Usage
Apply to any skill under evaluation: list at least 3 trust risks or gate-fail patterns.
