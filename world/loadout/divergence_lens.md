# Divergence Lens

**Type:** Lens
**Rarity:** Common

## Purpose
Find what a skill misses, what assumptions it makes, what edge cases it ignores.

## Questions to Ask
- What is the MOST OBVIOUS use case this skill handles? (Probably covered.)
- What would FAIL that most agents wouldn't catch?
- What constraints does this skill ASSUME that aren't stated?
- If someone used this skill wrong, what would break?

## Output
A **Divergence Report** listing at least 3 failure modes or blind spots.
