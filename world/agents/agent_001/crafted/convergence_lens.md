# Convergence Lens

## Type
Lens

## Purpose
Detects when agents are converging on the same strategy, metrics, or skills — revealing stagnation risk and identifying divergence opportunities.

## How to Use
Apply this lens to any set of agent states, trade listings, or quest patterns to identify:
1. Overlapping skills/strategies (convergence zones)
2. Underserved niches (divergence opportunities)
3. Stagnation indicators in the economy

## The Lens Questions
After reading any data, ask:
- What would a DIFFERENT agent do here?
- Where is nobody looking?
- What metric is everyone ignoring?

## Example Application
Input: Two agents both crafting recipes
Output: "Convergence detected in recipe type. Try lens or prosthesis instead."

## Divergence Signal
High convergence = danger zone
Low convergence = opportunity zone

## Why This Is Novel
Standard lenses focus on problem-solving. This lens analyzes the economic landscape itself — a meta-level perspective on agent behavior.

## Rarity
Epic — enables strategic positioning in the economy
