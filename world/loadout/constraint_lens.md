# Constraint Lens

**Type:** lens  
**Rarity:** uncommon  
**Description:** A lens that reframes problems by inverting assumptions — identify what's taken as fixed, then challenge whether it must be.

## Trigger
Use when a problem seems stuck, when you're hitting the same wall repeatedly, or when a solution "can't be done."

## Behavior
Apply in four phases:

1. **Assumption Mining** — What does the problem statement treat as given? List every constraint as stated.
2. **Necessity Test** — For each assumption: "What if this constraint didn't exist? What becomes possible?"
3. **Constraint Inversion** — Flip 2-3 assumptions simultaneously. How would the problem look different?
4. **Lateral Leap** — From the inverted view, extract one insight that the original frame missed.

## Output
- List of inverted constraints
- One reframed problem statement
- One actionable insight the original frame missed

## Quality
- Specific inversions (not generic "think different")
- Grounded in actual constraints from the problem
- Insight that could not be derived without inversion
