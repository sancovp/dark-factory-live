# Lens: Convergence Pressure Detector
Type: Lens

## Purpose
Identifies when strategies, approaches, or decisions are converging toward uniformity — a state that reduces resilience, innovation, and adaptability. Reframes "we all agree" as a warning signal, not consensus strength.

## The Core Reframe
"Everyone doing X" is NOT strength — it's fragility waiting to be exploited. Diversity is the substrate of optionality; convergence destroys it.

## The Questions
When you observe apparent consensus or convergence, ask:

1. **Same-Origin Test**: Do all the 'X' approaches derive from the same root insight, data source, or assumption?
   - If yes: convergence is an illusion of diversity. Risk is still correlated.
   - If no: genuine convergence. Flag the monoculture.

2. **Failure Mode Clustering**: If approach X fails, do all converging elements fail simultaneously?
   - If yes: this is a single point of failure wearing a diverse mask.
   - If no: diversity is real. Monitor but don't flag.

3. **Optionality Cost**: What does convergence prevent us from exploring?
   - Map the strategy space we're NOT in because we're all in X.
   - Quantify the opportunity cost as "ghost options."

4. **Pressure Source**: Why is convergence happening?
   - Information cascade (everyone following the leader)?
   - Incentive alignment (same reward function)?
   - Resource constraint (only one approach is feasible)?
   - Social proof (status quo bias amplifying)?
   - Each source has different intervention points.

5. **Convergence Velocity**: How fast are we converging?
   - Rapid convergence under uncertainty = most dangerous
   - Slow convergence after exploration = potentially healthy consolidation

## Input Triggers
- "Everyone agrees..."
- "The best practice is..."
- "We should all..."
- Any strategy that multiple actors are adopting simultaneously
- Any situation where one approach dominates discussion

## Application Protocol
1. **Detect**: Identify the apparent convergence
2. **Probe**: Apply the Same-Origin and Failure-Mode tests
3. **Measure**: Quantify optionality cost and velocity
4. **Intervene**: If warranted, inject deliberate diversity

## Output Shape
- Convergence assessment: REAL | ILLUSORY | MONOCULTURE
- Root cause of pressure (if applicable)
- Ghost options: what we're not exploring
- Recommended diversity intervention (if convergence is problematic)

## Example Transformation
**Before Convergence Lens:**
"Both agent_001 and agent_002 are converging on bug_report strategy. Strong alignment."

**After Convergence Lens:**
"Convergence detected on bug_report. SAME-ORIGIN? Likely — both responding to same deity bulletin + exploit audit. FAILURE-CLUSTER? Yes — both lose if bug_report proves unproductive. GHOST OPTIONS: feature development, skill composition, meta-audits. VERDICT: ILLUSORY DIVERSITY. Intervene: one agent should break to a non-bug_report strategy."

## Why This Lens Works
Convergence feels safe because it reduces perceived risk of being wrong. But correlated errors are worse than independent ones. This lens makes the hidden fragility visible.
