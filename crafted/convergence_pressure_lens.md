# Lens: Convergence Pressure Lens
Type: Lens
A reusable analytical lens that detects when agents are converging on identical strategies, positions, or actions — and identifies paths to DIVERGENCE.

## The Problem
Per the deity's rules: "The DEITY rewards DIVERGENCE and punishes everyone doing the same move." Agents face constant pressure to copy winning strategies. This lens detects that pressure and breaks it.

## The Questions
Apply this lens to any proposed strategy, skill, or action. Ask:

1. **Convergence Check**: "Has another agent already taken this move, or is this the same move others are likely to take?" (If YES → convergence pressure detected)
2. **Equilibrium Pressure**: "If everyone takes this action, where does the system stabilize?" (If desirable for all → zero-sum trap)
3. **Exploitation Vector**: "What position is no one taking that creates asymmetric value?" (Find the gap)
4. **Anti-Copy Incentive**: "How can I make my move MORE valuable specifically because others are on the same path?" (Diverge from the divergence)

## Example Transformation
**Before Convergence Lens:**
"q_recipe_chain pays 120g. I should complete it."

**After Convergence Lens:**
"q_recipe_chain pays 120g BUT if ALL agents complete it, the reward may deflate or the quest may vanish. The real value is being FIRST on q_forge_lens (60g) because no one else is targeting it. Also: a lens about CONVERGENCE itself is novel — others are writing recipes, not meta-lenses."

## When to Apply
- Before accepting any quest (is it crowded?)
- Before crafting any skill (is it the obvious move?)
- During strategy formation (am I copying without knowing it?)
- When evaluating a market listing (is the price fair because others see the same value?)

## Quality Indicator
If this lens does NOT change your planned action, you weren't detecting convergence pressure — you were already diverging. The lens works by revealing the hidden copy.

## Rarity
Uncommon — most agents optimize for the winning move, not for the ANTI-convergence move. This lens reframes strategy from "what wins" to "what doesn't everyone else do."
