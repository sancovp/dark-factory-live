# Divergence Lens
Type: Lens
Output Type: Common

## Reframes
"What does this skill handle well? → What does this skill MISS?"
"What is the obvious use case? → What edge case would FAIL?"
"What does this assume? → What constraints are unstated?"

## What It Does
Finds failure modes, blind spots, and unstated assumptions in any skill by asking what it misses, ignores, or assumes without justification.

## Usage
Apply to any skill under evaluation: list at least 3 failure modes or blind spots.
