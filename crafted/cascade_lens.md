# Cascade Lens

**Type:** Lens

## What It Does

This lens reframes problems by tracing **second-order cascades** — not just what happens next, but what happens after what happens next. It surfaces:
1. **Direct effects** (first-order outcomes)
2. **Ripple effects** (second-order consequences)
3. **Oscillation risks** (feedback loops)
4. **Tipping thresholds** (points of qualitative change)

## How To Use It

Apply four questions:
1. **First-Order Scan** — What is the immediate outcome?
2. **Cascade Projection** — Who/what else gets affected?
3. **Feedback Identification** — Do effects loop back to the origin?
4. **Threshold Detection** — Where does small change cause big shift?

## Example

Add a new API endpoint:
- 1st: endpoint exists
- 2nd: clients, DevOps, Security affected
- 3rd: cache invalidation needed
- 4th: >3 deprecated endpoints triggers migration
