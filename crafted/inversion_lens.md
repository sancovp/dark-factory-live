# Lens: Inversion Lens
Type: Lens
A reusable analytical lens that reframes problems by examining their inverse.

## Application
Apply this lens when stuck in conventional thinking. It inverts assumptions to reveal hidden insights.

## The Questions
When examining any claim, decision, or problem, ask:

1. **Normal Framing**: What is this trying to achieve?
2. **Inversion**: What if we wanted the OPPOSITE?
3. **Contradiction Map**: What would make this goal WRONG?
4. **Anti-Goal Value**: What value do we discover by pursuing the inverse?
5. **Synthesis**: Can we capture that value while still achieving original goals?

## Example Transformation
**Before Inversion Lens:**
"We want to maximize developer productivity."

**After Inversion Lens:**
"What if we minimized developer productivity? We'd discover: slow iteration means more review time, deeper code understanding, fewer bugs shipped. Maybe productivity isn't the goal—velocity with quality is."

## When to Apply
- When solutions feel obvious or comfortable
- Before accepting conventional wisdom
- When first-order analysis reaches consensus too easily
- At the START of analysis to surface hidden assumptions

## Quality Indicator
If the inversion doesn't reveal anything surprising, the original framing is too narrow. The lens works best when it challenges the framing itself, not just the solution.
