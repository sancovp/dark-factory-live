# Recipe: Causation-Risk Pipeline
Type: Recipe
Output Type: Towering (Epic)
Yield: 1 dual-lens analysis skill combining cause mapping with risk inversion

## Ingredients
1. Lens: Causation Lens (Uncommon) — maps cause-effect relationships
2. Lens: Risk Inversion Lens (Uncommon) — reframes failure as success criteria
3. Template: Structured Decision Template (Common) — provides output framework

## Assembly
1. Start with your input (decision, system, or outcome to analyze)
2. Apply the Causation Lens FIRST:
   - Map all upstream causes (what created this?)
   - Map all downstream effects (what does this create?)
   - Identify the PRIMARY causal chain (which causes matter most?)
3. Apply the Risk Inversion Lens to each effect:
   - "What would SUCCESS look like?" → treat as the failure to avoid
   - "What would FAILURE look like?" → treat as the success to achieve
   - Invert: flip failure and success markers
4. Cross-reference:
   - Which causes MOST directly produce the inverted-success outcomes?
   - Which causes produce the inverted-failure outcomes we want to avoid?
5. Using the Structured Decision Template:
   - Fill causes and effects
   - Mark each with inverted risk scores
   - Highlight the PRIMARY causal chain with risk-inverted priorities
6. Output a ranked action list where:
   - TOP priority = cause that creates desired outcome
   - BOTTOM priority = cause that creates undesired outcome

## Quality Check
- Remove Causation Lens. Can you map causes without it? (Must: no → lens essential)
- Remove Risk Inversion Lens. Can you invert risks without it? (Must: no → lens essential)
- Remove both lenses. Is the template output meaningful? (Must: no → combination creates value)

## Expected Rarity
- Two Uncommon lenses + Common template → Epic output
- Each lens adds irreplaceable perspective; together they create a decision framework that neither could produce alone

## Why This Recipe Works
Causation without risk framing produces maps without priorities. Risk inversion without causation produces priorities without understanding. The combination forces you to both understand the system AND know where to intervene.
