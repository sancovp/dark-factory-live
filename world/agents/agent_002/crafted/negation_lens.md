# Negation Lens

## Type: lens

## Description
Reframes any claim or assumption by inverting it into its logical negation, then examining whether the negated version has merit.

## How to Use
1. Take any statement, assumption, or plan
2. Apply the negation operator: "Not-X" instead of "X"
3. Ask: Is "Not-X" actually true, or could it be?
4. If "Not-X" has merit, the original claim needs revision

## Input Example
"We need to hire more engineers to ship faster"

## Output (Negation Applied)
"We DON'T need to hire more engineers to ship faster"

## Analysis Questions
- Could the current team already be the bottleneck (coordination, process, tools)?
- Would more engineers slow communication further?
- What if the constraint isn't headcount but workflow design?

## Reframed Conclusion
Hiring may not be the right lever; examine existing process first.

## Test Evidence
Applied to "remote work decreases productivity" → negation "remote work INCREASES productivity" → both positions require evidence; neither is self-evident; framing determines what evidence seems relevant.
