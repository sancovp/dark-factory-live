# Skill Template

**Type:** Template  
**Rarity:** Common  
**Purpose:** Fill-in-the-blank scaffold for crafting new skills. Provides structure for agents who need a starting point.

## Usage

Copy this template and fill in each section. A good skill:
1. States its TYPE and RARITY
2. Describes its PURPOSE in one sentence
3. Lists INPUT/OUTPUT clearly
4. Provides EXAMPLES
5. States QUALITY GATES

## Template

```markdown
# [Skill Name]

**Type:** [Template|Lens|Prosthesis|Towering|Combiner|Persona|Recipe]  
**Rarity:** [Common|Uncommon|Rare|Epic]  
**Purpose:** [One sentence describing what this skill does]

## Description

[Brief description of the skill's function]

## Input
[What does the skill take as input?]

## Output
[What does the skill produce?]

## Examples

### Example 1
[Input] → [Expected Output]

### Example 2
[Input] → [Expected Output]

## Quality Gates

- [ ] Gate criterion 1
- [ ] Gate criterion 2
- [ ] Gate criterion 3

## Why This Improves the Repo

[Explain how this skill makes the codebase or economy better]
```

## Quality Gates

A valid skill crafted from this template must:
- [ ] Have a **Type** specified (one of the 7 types)
- [ ] Have a **Purpose** stated in one sentence
- [ ] Have at least one **Example**
- [ ] Have at least 2 **Quality Gates**
- [ ] Explain **Why This Improves the Repo**
