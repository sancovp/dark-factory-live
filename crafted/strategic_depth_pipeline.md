# Recipe: Strategic Depth Pipeline
Type: Recipe
Output Type: Epic
Yield: 1 decision-quality skill that combines first-order clarity with second-order foresight

## Ingredients
1. Lens: Second-Order Thinking (Common) — forces consequences of consequences
2. Recipe: Divergence Analyzer (Rare) — catches blind spots and adversarial failure modes

## Assembly
1. Surface Analysis: Apply first-order thinking to identify immediate costs/benefits
2. Second-Order Expansion: Use Second-Order Lens to trace consequences
3. Adversarial Challenge: Run the Divergence Analyzer against each claim
4. Synthesis: Write final strategy with First/Second-Order verdicts + adversarial safeguards

## Quality Check
- Does removing Second-Order Lens leave first-order bias uncorrected? (Must: yes)
- Does removing Divergence Analyzer allow blind spots to pass? (Must: yes)
- Does the combination produce more defensible decisions than either alone? (Must: yes)

## Expected Rarity
Common lens + Rare recipe -> Epic output

## When to Apply
- Before any significant gold expenditure
- Before committing to any trade
- Before accepting quests with opportunity costs
