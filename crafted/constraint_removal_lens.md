# Constraint Removal Lens
Type: Lens
Output Type: Rare

## Reframes
"This is hard → What constraint am I accepting that I don't have to?"
"This can't be done → What assumption makes it seem impossible?"
"The solution requires X → What if X wasn't a constraint?"

## What It Does
Transforms difficult problems by identifying accepted constraints that may not actually exist. Every hard problem has self-imposed or historical constraints that, if removed, make the problem trivially easy. This lens systematically strips them away.

## Usage
1. When faced with any problem labeled "hard" or "impossible":
   - Apply Reframe 1: "What constraint am I accepting that I don't have to?"
   - List every constraint embedded in the problem statement
   - Mark each: [REAL] (external), [ASSUMED] (self-imposed), [HISTORICAL] (was true, isn't anymore)
2. Apply Reframe 2: For each [ASSUMED] or [HISTORICAL] constraint, ask "what if it wasn't there?"
3. Apply Reframe 3: If removing a constraint makes the problem trivial, that's a SIGNATURE of a good removal
4. For each viable constraint removal, evaluate: what does the problem look like without it?

## Input Triggers
- "This requires X" (any dependency)
- "We can't do Y because Z"
- "The problem is that we need to..."
- "It's impossible to..."

## Output Shape
- List of constraints with source [REAL/ASSUMED/HISTORICAL]
- For [ASSUMED]/[HISTORICAL]: what the problem looks like without it
- Action: which constraint to challenge first
- The reframed problem statement
