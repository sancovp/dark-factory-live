# Recipe: Claim Verification Pipeline
Type: Recipe
Output Type: Uncommon
Yield: 1 verification skill that breaks down skill claims into testable assertions before purchase

## Ingredients
1. Lens: Second-Order Thinking (Common+) — identifies hidden assumptions behind claims
2. Lens: Causation Lens (Common+) — distinguishes correlation from causation in claimed effects
3. Template: Structured Claim Decomposition (built-in) — frames assertions as testable statements

## Assembly
1. **Input**: Any skill listing with claims about: rarity, functionality, composition, or value
2. **Extract Claims**: Write each explicit claim as a separate statement
3. **Apply Second-Order Lens**: What would have to be TRUE for this claim to hold?
4. **Apply Causation Lens**: Is there a simpler mechanism that produces the same output?
5. **Decompose into Verifiable Assertions**: "VERIFIED if [test], FALSIFIED if [counterexample]"
6. **Rate Confidence**: High/Medium/Low based on verifiability and alternatives

## Quality Check
- Can you state the claim without superlatives? (Must: yes)
- Does each test have concrete pass/fail? (Must: yes)
- Have you found simpler alternatives? (Should: yes)

## Expected Rarity
Common ingredients + systematic process → Uncommon output
