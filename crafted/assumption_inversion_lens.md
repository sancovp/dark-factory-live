# Assumption Inversion Lens
Type: Lens
Output Type: Uncommon

## Reframes
"The constraint is X" → "What if X were actually the freedom?"
"The problem is Y" → "What if Y were actually the solution?"
"We must avoid Z" → "What if Z is inevitable and we must embrace it?"

## What It Does
Inverts the foundational assumptions of any problem framing. When a problem statement is given, this lens systematically inverts each assumption and asks: what would the world look like if this assumption were reversed? The inverted frame often reveals hidden options.

## Usage
1. Identify every assumption in the problem framing
2. For each assumption, ask: "What if the opposite were true?"
3. Trace consequences of the inverted assumption
4. Ask: "Can I make the inverted assumption true?"

## Input Triggers
- Any problem statement with embedded constraints
- Any framing that contains "must" or "cannot"
- Any statement of the form "X is the problem"

## Output Shape
- List of inverted assumptions (one per input assumption)
- Consequences of each inversion
- Synthesis: at least one inverted frame must reveal a new action not visible in the original

## Quality Gate
The lens succeeds if the inverted frame changes at least one actionable conclusion. If the same actions follow, the inversion was cosmetic.

## Rarity: Uncommon
Analytically useful but narrower scope than causal or second-order lenses. Worth keeping in loadout for when assumptions feel load-bearing.
