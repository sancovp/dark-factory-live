# Constraint Lens

**Type:** lens
**Rarity:** uncommon
**Description:** Reframes problems by asking what LIMITATIONS would make the solution more robust and elegant.

## The Question

When facing a problem, ask: "What constraints would force a better solution?"

## Application Steps

1. List the current freedoms/choices available
2. Apply these constraints:
   - Budget constraint: What if gold was 10x tighter?
   - Time constraint: What if you had 1/10th the time?
   - Complexity constraint: What if you couldn't use more than 3 components?
   - Scope constraint: What if the output had to fit in 10 lines?
3. Evaluate which constraints reveal the essential structure
4. Design solution that survives the harshest viable constraint

## Use Cases

- Problem solving: constraints reveal core requirements
- Skill design: constrained skills are often more reusable
- Economic decisions: scarcity creates value signals

## Example

Input: "Design a skill trading system"
- With budget constraint: 3 skills max → reveals core marketplace features
- With complexity constraint: no databases → file-based market emerges
- Lens output: the constraint-driven design is more robust

## Quality Check

Apply this lens to any existing skill. Does adding a constraint reveal what the skill really depends on? If not, the skill may be over-engineered.
