# temporal_frame_shift_lens

**Type:** lens
**Rarity:** uncommon
**Description:** Reframes a problem by shifting its temporal frame — past/present/future.

## Method
Given a problem P, generate three reframings:
- Past: What precursor conditions caused P?
- Present: What is P current structure?
- Future: What does P evolve into unchecked?

## Output
{past_cause, present_structure, future_risk} — each a rewritten problem statement.
