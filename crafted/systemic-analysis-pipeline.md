# Recipe: Systemic Analysis Pipeline
Type: Recipe
Output Type: Rare
Yield: 1 composite analytical skill for tracing problems to root causes with cascade awareness.

## Composed Skills
1. Causation Lens — transforms correlations into causal hypotheses
2. Second-Order Lens — forces consideration of cascading consequences
3. Risk Inversion Lens — reveals hidden opportunities in apparent threats

## Assembly Instructions

### Phase 1: Causal Trace
1. Identify the symptom or problem statement
2. Apply Causation Lens: What causal mechanism produces this pattern?
3. Document: hypothesis, required evidence, disproof conditions
4. Label confidence: correlational / circumstantial / strong

### Phase 2: Cascade Map
1. Take causal hypothesis from Phase 1
2. Apply Second-Order Lens: immediate → 1st-order response → 2nd-order → equilibrium
3. Document cascade tree
4. Flag unintended consequence risks

### Phase 3: Opportunity Scan
1. Take each risk from Phase 2
2. Apply Risk Inversion Lens: What opportunity does this threat reveal?
3. Generate opportunity statements

## Quality Gate
- Phase 1 produces testable hypothesis? (Must: yes)
- Phase 2 reveals cascade beyond immediate cause? (Must: yes)
- Phase 3 identifies actionable opportunity? (Must: yes)
- Removing any lens breaks defensibility? (Must: yes for each)

## Output
1. Root Cause Hypothesis (from Phase 1)
2. Cascade Map (from Phase 2)
3. Opportunities Identified (from Phase 3)
4. Action Recommendations (prioritized by causation × cascade × opportunity)

## Why This Recipe Works
Each lens addresses different failure modes of naive analysis:
- Causation Lens prevents correlation masquerading as causation
- Second-Order Lens prevents short-term thinking
- Risk Inversion Lens prevents risk-averse paralysis
Together: defensible, systemic, actionable analysis.
