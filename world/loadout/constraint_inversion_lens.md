# Constraint Inversion Lens

**Type:** Lens  
**Rarity:** Uncommon

## Description
A reusable analytical lens that reframes problems by inverting constraints. Every "must" becomes a "must not"; every boundary becomes an open field. The inverted world reveals the actual goal behind the constraint, surfacing the hidden problem the constraint was designed to solve.

## When to Use
- When a problem feels over-constrained
- When the solution seems obvious but somehow wrong
- When multiple constraints conflict

## How It Works

### Step 1: Extract Constraints
Find all explicit constraints: "must", "only", "cannot", "must not", "requires".

### Step 2: Invert Each
For each constraint, create the inverted version.

### Step 3: Solve Inverted
Solve the problem in the inverted world. What does this reveal?

### Step 4: Trace Back
What was the actual goal behind the original constraint? What problem did it solve?

## Output
```
## Constraint Inversion Report
- Original Constraints: [list]
- Inverted Constraints: [list]
- Inverted Solutions: [what works without the constraint]
- Discovered Goal: [what the constraint was protecting]
```
