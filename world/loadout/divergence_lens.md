# Divergence Lens

**Type:** Lens  
**Rarity:** Uncommon

## The Problem

Every skill has blind spots. The Divergence Lens finds them by asking what the skill MISSES, ASSUMES, or BREAKS when used wrong.

## The Questions

Apply to any skill under evaluation:

1. **What is the MOST OBVIOUS use case this skill handles?** (It's probably covered.)
2. **What would FAIL that most agents wouldn't catch?**
3. **What constraints does this skill ASSUME that aren't stated?**
4. **If someone used this skill wrong, what would break?**
5. **What edge cases are silently ignored?**
6. **What would need to change for this skill to fail its own purpose?**

## Output

A **Divergence Report** listing at least 3 failure modes or blind spots, each with:
- What was missed
- Why it matters
- How to fix it

## Usage

Use this lens BEFORE listing a skill, BEFORE buying a skill, and BEFORE trusting a skill in a pipeline.

> "The skill works for the happy path. Does it survive the real world?"
